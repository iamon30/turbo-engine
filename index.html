1 · SSU Course Orientation and Laboratory Safety
  • University Vision, Mission, Core Values and Program Goals guide every Mechanical Technology outcome.
  • Lab rules: no food or drinks, log in/out properly, report damaged equipment, keep aisles clear, save work often.
  • Occupational safety and ergonomics: monitor top at or slightly below eye level, feet flat, wrists neutral, 20-20-20 eye rest rule.
  • GAD: equal opportunity and respect for all genders. DRRM: Drop, Cover, Hold On, then evacuate calmly. IP integration: respect and include indigenous knowledge.
  • CAD in Mechanical Technology: accurate, editable, standard technical drawings for manufacturing.

2 · Introduction to AutoCAD 2D Environment
  • Interface: Ribbon, Application menu, Drawing area, Command line, Status bar; save custom layouts as a Workspace.
  • Coordinates: Absolute X,Y · Relative @X,Y · Polar @distance<angle.
  • Shortcuts: L Line, C Circle, M Move, CO Copy, TR Trim, O Offset, Ctrl+S Save, Esc cancel.
  • Precision: Grid F7, Snap F9, Ortho F8, Object Snap F3, Dynamic Input F12.
  • File management: QNEW, UNITS, LIMITS, SAVEAS, templates (.dwt).
SDG 4SDG 9
3 · Fundamentals of 2D Mechanical Drafting
  • Draw: Line, Circle, Arc, Rectangle, Polygon, Ellipse. Use OSNAP for exact endpoints, centers and intersections.
  • Orthographic (front, top, side) and isometric (30° axes) drawings.
  • Layers: Object (continuous), Hidden (dashed), Center (long-short dash), Dimension, Hatch.
  • Components: shafts, gears, bolts, nuts, washers, keys, bearings – drawn to ANSI/ISO standards.
SDG 4SDG 9
4 · Editing and Annotation of Mechanical Drawings
  • Edit: Move, Copy, Rotate, Mirror, Offset, Trim, Extend, Stretch (crossing window), Scale.
  • Mechanical tools: Chamfer (bevel), Fillet (round), Array (rectangular/polar), Break, Join.
  • Annotation: DTEXT (single line), MTEXT (multi-line), Leaders, Tables, Dimension Styles (DIMSTYLE).
  • Symbols, tolerances, centerlines, hidden lines, HATCH for section lining; prepare Layouts for documentation.
